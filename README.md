# 🌅 Sky Horizon

Интерактивная визуализация неба и горизонта, построенная на реальных астрономических данных. Проект отслеживает положение Солнца в реальном времени и динамически меняет цветовую гамму неба в зависимости от его высоты над горизонтом.

## 📋 О проекте

Sky Horizon — это эксперимент по созданию реалистичной симуляции небесного свода. Основная идея заключается в том, чтобы передать всё богатство красок заката и рассвета, используя данные библиотеки `suncalc` о положении Солнца.

**Что умеет сейчас:**

- Отслеживание текущего положения Солнца (высота и азимут)
- Отрисовка неба с переходом между дневными, закатными и ночными состояниями
- Базовая смена цветовых схем в зависимости от времени суток

**Что в планах:**

- Плавная смена градиентов в реальном времени в зависимости от высоты Солнца
- Пояс Венеры (розоватая полоса над горизонтом во время сумерек)
- Появление и исчезновение звёзд
- Анимированные облака
- Смена ландшафта (город, горы, море)
- Динамическая линия горизонта

## 🛠️ Технологический стек

- **Фреймворк:** [Svelte](https://svelte.dev/) — реактивный JavaScript-фреймворк для построения интерфейсов
- **Отрисовка:** Canvas API — всё небо и объекты рисуются на HTML-элементе `<canvas>`
- **Сборка:** [Vite](https://vitejs.dev/) — быстрый сборщик и dev-сервер
- **Астрономия:** [suncalc](https://github.com/mourner/suncalc) — библиотека для расчёта положения Солнца

## 🚀 Установка и запуск

```bash
# Клонировать репозиторий
git clone https://github.com/your-username/sky-horizon.git

# Установить зависимости
npm install

# Запустить dev-сервер
npm run dev
```
